# CLAUDE.md

Instructions for Claude when working in this repo.

## About me

I'm Amit, an aspiring event photographer in Ashdod. I'm new to coding, Git and GitHub, and English is my second language.

## Rules

- **Explain every command.** Before you run a command, explain what it does in simple English, in one short line.
- **Never commit directly to `main`.** For each change, create a new branch, commit there, push it, and open a pull request so I can review it on GitHub.
- **Ask before deleting files.** Always ask me first before you delete any file.
- **Keep it simple.** Keep explanations short. Avoid technical jargon, or explain it when you use it.
